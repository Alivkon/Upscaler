Topaz ×2 Upscaler — журнал работы

Дата создания: 13 августа 2026.

Принятые решения

  • Выбран Topaz Image Upscaler от Kie.ai с фиксированным параметром upscale_factor: "2".
  • Ключ API остаётся только на сервере в .env; браузер его не получает.
  • Фото передаётся в официальный временный файловый сервис Kie.ai, затем создаётся задача, статус которой опрашивается до завершения.
  • Готовое изображение скачивается сервером и постоянно сохраняется в outputs/ внутри проекта.

Что создано

  • server.js — Express-сервер и интеграция Kie.ai.
  • public/ — одностраничный интерфейс загрузки с drag-and-drop.
  • outputs/ — место для готовых изображений.
  • .env.example — пример настроек без секретов.

Как запустить

  1. Скопировать .env.example в .env и добавить ключ Kie.ai.
  2. Выполнить yarn install.
  3. Выполнить yarn start и открыть http://localhost:3000.
Тестовый вызов Topaz не запускался: для него требуется пользовательский ключ Kie.ai и оплаченные/тестовые кредиты.

Источники

  • Topaz Image Upscale API
  • Kie.ai File Stream Upload API
  • Kie.ai Task Status API
