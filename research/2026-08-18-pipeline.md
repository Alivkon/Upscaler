# Selection pipeline — current state

18 August 2026. Synthesises `frame-strategy.md` and `crop-instead-of-reject.md`
into a single pipeline reference. Earlier docs remain; this one supersedes their
pipeline order sections.

---

## Pipeline order

Steps 1–6 are free (metadata or CPU). Steps 7–9 call Replicate and cost money.
Step 10 is a human eye check that cannot be automated.

```
1.  API query         — filter by work type at source (painting, landscape, still life)
2.  Name filter       — title heuristic + dictionary/corpus: reject real-person portraits
3.  Object filter     — medium + title keywords: reject textiles, vessels, furniture
4.  Download thumbs   — ≥ 500 px; frame_gate loses accuracy below that
5.  Numerical box     — luma median, warmth (R−B)/luma, colour p95 outside sepia,
                        busyness, aspect ratio — all CPU, thresholds in frame-strategy.md
6.  Monochrome filter — medium text: reject pen/ink/graphite/etc. unless colour keyword cancels
7.  frame_gate.py     — pixel rule: detect mat/border/frame around the work
8.  Qwen — people     — paid; runs only on survivors of 1–7
9.  Qwen — frame      — paid; frame strategy (see below) runs after step 8
10. Crop + recheck    — free if crop boxes already cached; see below
11. Eye check         — NONE class cannot be published without a human look; pool is small
12. Download masters  — TIF/full-size, finalists only
```

## Frame strategy (step 9)

Depends on whether the medium is oil (`'oil' in technique.lower()`).

**Oil paintings** — Qwen runs always, regardless of frame_gate verdict.
Reject if frame_gate **or** Qwen sees a frame (OR logic).
Rationale: frame_gate has four known false positives on European oil — it reads a
painted niche or dark canvas edge as a mat. Both signals needed; neither alone is enough.

**Everything else** — frame_gate alone decides the clean path:
- frame_gate says clean → trust it, do not call Qwen, work passes.
- frame_gate says frame → call Qwen.
  - Qwen also says frame → reject (proceed to step 10).
  - Qwen says clean → save the work (frame_gate false positive).

Numbers from the 89-work simulation:

| | OR everywhere (old) | This strategy |
|---|---|---|
| Qwen calls | 89 | 77 |
| Works passing | 18 | 36 |

## Crop + recheck (step 10)

Works rejected at step 9 are not discarded immediately. If a crop box is cached
(from a prior Qwen session in `crop_boxes.json`), apply it for free:

1. Check `crop_boxes.json` for the work's file.
2. If a box exists and trim is < 35% on every side (`MAXTRIM` in `frame_crop.py`),
   apply the crop.
3. Re-run `frame_gate.py` on the cropped image.
   - Passes → work is saved.
   - Still fails → reject.

If no box is cached, a new Replicate call is needed — do not run without approval and
a count of planned calls.

**Known limitation: the cropper under-crops.** It locates the work approximately and
leaves a border. In the 24-work trial, frame_gate passed only 2 after cropping.
A second-pass fix is possible (the residual border is a narrow uniform-tone strip that
frame_gate can measure reliably), but has not been applied. The cropper currently
returns 11 works where frame_gate had fired but Qwen found nothing to cut — those are
frame_gate false positives, not crops.

**What the cropper actually returns** (from the 24-work trial):
16 prints (14 of which are covers from a single album), 6 textiles, 2 paintings.
The textiles reveal an object-filter gap: Art Institute medium fields use a different
format than Cleveland, and the keyword rule misses them. Fix the object filter for AIC
before running the cropper again.

## What each gate knows it can't see

- **Name filter**: catches portrait keywords and artist-dash-sitter format; misses
  untitled and numbered works. Qwen (step 8) covers the gap.
- **frame_gate.py**: precision 91.4%, recall 98.7% on 407 labelled works — none from
  AIC or CLE, so true precision on those pools is unmeasured.
- **Qwen — people**: precision on NONE class ~75–87.5% (eye-check of 16 works,
  18 Aug 2026). Publish NONE class only after a human look. 1042 rejected works
  have not been reviewed in the other direction — recall is unmeasured.
- **Crop**: boxes from a neighbouring session (calls already paid). New calls needed
  for the 32 works that have no box yet.
