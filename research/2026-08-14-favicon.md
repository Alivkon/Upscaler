# Сессия: фавикон под существующий дизайн

Дата: 2026-08-14

## Задача
Придумать и реализовать favicon под имеющийся дизайн одностраничного апскейлера фото (×2).

## Палитра проекта (из public/styles.css)
- `--ink: #17352e` — тёмно-зелёный (текст, кнопки)
- `--paper: #f6f1e8` — кремовый фон
- `--lime: #d9f25f` — лаймовый акцент (иконка загрузки, блюр-пятно)
- `--white: #fffdfa` — карточки/поверхности
- `#df6242` — коралловый акцент (em в заголовке)

## Мотивы бренда
- «AI image upscaler», «×2 UPSCALE», «Увеличить фото ×2»
- В интерфейсе уже есть SVG-иконка «фоторамка + угловые скобки-расширение» (viewBox 0 0 48 48).
  Это буквальный символ «увеличить/апскейлить».

## Выбранная концепция (Вариант A)
«Рамка фото + углы-расширение» в фирменных цветах:
- Скруглённый квадрат `--ink` — фон (читается и на светлых, и на тёмных вкладках).
- Белая фоторамка (`--white`) внутри.
- Внутри — лаймовые «гора» + «солнце» (отсылка к иконке загрузки из интерфейса).
- В двух противоположных углах — лаймовые скобки-«расширение» (метафора апскейла).

## Альтернативы (запасные)
- B: «×2» — текстовый знак (цифра лаймом, крестик кораллом).
- C: лаймовый скруглённый квадрат с тёмно-зелёной иконкой расширения (перекличка с круглой
  лаймовой кнопкой загрузки `↥` в дропзоне).

## Реализация
- `public/favicon.svg` — векторная версия (для современных браузеров, чёткая на любых размерах).
- Растровые PNG (16/32/180 apple-touch) генерируются чистым Node (в проекте нет ImageMagick/rsvg;
  на машине есть только Node v20 + yarn). Генератор: `scripts/gen-favicon.mjs` (свой PNG-энкодер
  на zlib + растеризация фигур с суперсэмплингом для сглаживания).
- Подключение в `public/index.html` (`<head>`): rel=icon svg + png fallback + apple-touch-icon.
  Статика уже раздаётся через `express.static(public)` — сервер менять не нужно.

## Результаты экспериментов
- SVG и PNG построены по единой геометрии (пространство 0..100), кодирование PNG проверено.
