# Открытые коллекции как источник картинок для витрины

## Цель

Найти картинки под свободной лицензией, которые годятся в обои на телефон и
рабочий стол. Отдельно проверялась гипотеза: бывают ли хорошие работы, которых
**нигде в вебе нет в большом размере** — тогда апскейл даёт то, чего больше
взять негде.

## Что сделано

Забраны все работы CC0 с изображениями из API Cleveland Museum of Art
(41 434 записи), измерено собственное максимальное разрешение музея по каждой.
Скрипты остались во временном каталоге сессии, в репозиторий не добавлялись.

API keyless, но без заголовка `User-Agent` отвечает `403`.

## Результат: гипотеза о редкости не подтвердилась

Собственный максимум музея по длинной стороне:

| Длинная сторона | Работ | Доля |
|---|---|---|
| до 1000 px | 4 | 0,0 % |
| 1000–1920 px | 248 | 0,6 % |
| 1920–2560 px | 666 | 1,6 % |
| 2560–3840 px | 2 667 | 6,4 % |
| **3840 px и больше** | **37 849** | **91,3 %** |

Музей сканирует в высоком разрешении как правило, а не как исключение.
В «редкой» полосе 700–2560 px остаётся 918 работ, и это **298 монет,
66 украшений, 38 пряслиц** — мелкие предметы, снятые мелко. Для обоев
не годится.

Вывод: Cleveland не источник редкого материала. Проверять эту гипотезу нужно
на коллекциях с неровным качеством оцифровки, а не на музее с программой
открытого доступа.

## Что оказалось ценным вместо этого

Работы не редкие, но **ненаходимые**. Проверка через TinEye по двум работам:

| Работа | Максимум у музея | Максимум в остальном вебе |
|---|---|---|
| Ткань наска «Mantle» (`1946.226`) | 5000 × 2698 | 500 × 377 (eBay) |
| Вальдмюллер, «Prater Landscape» (`1983.155`) | 1902 × 1536 | 1902 × 1536 (Wikimedia) |

По ткани — всего 3 результата на 85,4 млрд проиндексированных картинок, в
Wikimedia её нет. Большой файл существует, но лежит в музейном API, куда никто
не заходит; в поиске по картинкам работы фактически нет выше 500 px.

Отбор по типам плоской графики (ткань, ковёр, гобелен, гравюра, лак, эмаль,
мозаика, вышивка, рисунок, рукопись) с длинной стороной от 2000 px и
соотношением сторон 0,35–3,2 даёт **22 920 работ**, из них:

- 16 256 дают кадр 16:9 в 4K, если считать по размеру TIFF;
- 22 213 дают кадр 1440p;
- 22 159 дают кадр под современный телефон.

## Поправка: у музея два разных файла, и это меняет вывод

Первый расчёт считал по размеру `full` — это TIFF. Удобный JPEG (`print`)
**обрезан до 3400 px по длинной стороне у 39 354 работ из 41 434** (95 %).
Кадр 16:9 из него — максимум 3400×1912, то есть до 4K не дотягивает.

Замер по выборке из 81 работы:

| Путь | Достают 4K | Достают 1440p |
|---|---|---|
| JPEG (`print`, ≤3400 px) | **0 из 81** | 59 из 81 |
| TIFF (`full`) | 81 из 81 | 81 из 81 |

Размер TIFF: медиана 69 МБ, 90-й процентиль 196 МБ, максимум 2,6 ГБ;
длинная сторона доходит до 237 091 px.

Вывод меняется: «апскейл не нужен» верно только если качать TIFF по 69 МБ.
По удобному пути 4K не получается ни у одной работы, и нужен апскейл
примерно в 1,13×. Это как раз тот зазор, ради которого сервис и существует.

## Ограничения

- Измерен только Cleveland. Met, Art Institute и Internet Archive проверялись
  отдельно; результат — в своей записи.
- NYPL Digital Collections и Biodiversity Heritage Library не проверялись:
  их API требуют ключа.
- TinEye на бесплатном тарифе ограничивает частоту запросов, сплошную
  проверку всех работ так не сделать. Годится как выборочная проверка.
- Соотношение сторон и разрешение измеримы, «читается ли иконка на фоне» —
  нет. Это решается только глазами.

## Источники

- Cleveland Museum of Art Open Access API — `https://openaccess-api.clevelandart.org/api/artworks/`
- TinEye, поиск по URL с сортировкой по размеру — `https://tineye.com/search?url=<URL>&sort=size&order=desc`
