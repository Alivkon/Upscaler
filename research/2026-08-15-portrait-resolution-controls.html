Выбор разрешения 2K и 4K для портретов

Цель и решение

Для Nano Banana Pro и Nano Banana 2 добавлены кнопки 2K и 4K. Значение передаётся в параметре resolution API Replicate.

Изменения

  • public/index.html: добавлены кнопки выбора разрешения.
  • public/app.js: выбор показывается только поддерживающим моделям.
  • server.js: разрешение передаётся в API.

Ограничения

Базовая Nano Banana не принимает параметр разрешения, поэтому кнопки для неё скрыты.

Источники

  • Nano Banana Pro API на Replicate
  • Nano Banana 2 API на Replicate
