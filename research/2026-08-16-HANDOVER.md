# Handover — 16 августа 2026

Состояние работы над позиционированием, названием и дизайном.
Написано перед сжатием контекста. Всё, что нужно, чтобы продолжить с этой точки.

---

## 1. Что это за продукт (изменилось за сессию)

Было: инструмент-апскейлер (`topaz-x2-upscaler`, см. `server.js`).

Стало: **курируемая галерея обоев для телефона**, наполняемая через апскейл,
плюс платный инструмент апскейла как источник монетизации.

Уточнения от Charlie, важные для всех решений:

- Это **не** соцсеть и не лента для скроллинга от скуки. Человек приходит
  примерно раз в год, когда купил новый телефон. Ретеншена нет by design.
- **Трёх изображений в день достаточно**, Charlie готов заливать их сам.
  Значит, задачи cold-start и плотности контента не существует.
- Собственный сценарий Charlie и есть сценарий целевого пользователя:
  гуглит `vertical minimalist wallpaper`, `vertical aesthetic wallpaper pinterest`,
  смотрит **Google Images**, листает много плохого, хочет, чтобы там было хорошее.
- Монетизация нужна хотя бы для выхода в ноль по расходам на апскейл.

**Следствие:** Google Images — основной канал. Страница одного изображения —
это и есть главная страница.

## 2. Результаты исследования (данные, не мнения)

Метод: Google Trends API (12 мес.), Google Autocomplete, Pinterest, RDAP/whois.
Подробности — в `2026-08-16-keyword-research-naming.md` (+ `.html`).

|---|---|

| `aesthetic wallpaper` | 30.4 |
| `hd wallpaper` | 13.6 |
| `wallpaper download` | 12.3 |
| `minimalist wallpaper` | 2.4 |

Частоты в корпусе автодополнения (1607 запросов): `4k` — 331, `hd` — 274,
`download` — 233, `aesthetic` — 226.

### Устройство и существительное (US)

`iphone wallpaper` 28.9 > `phone wallpaper` 12.1 > `phone background` 10.6.

### Форма выигрышного запроса

`4k` — не альтернатива эстетическим словам, а **комбинатор**: он верхний суффикс
у всех сидов. Целевая форма — `<эстетика> wallpaper 4k <устройство>`,
например `minimalist wallpaper 4k phone`. Именно это Charlie и производит:
красивая картинка, реально 4K, реально вертикальная.

### Ловушка: «vertical»

Автодополнение `vertical wallpaper` — про **вертикальные мониторы**
(`for pc`, `1920x1080`, `vertical monitor`, `wallpaper engine`), не про телефоны.
Это слово Charlie, но не аудитории. Страницы на нём не строить.

### Pinterest: `4k` — маркер чужого вкуса

- `minimalist phone wallpaper` → японские иероглифы, тушь, луна, сады.
  Чипы Pinterest: *Simple iphone backgrounds aesthetic / dark*, *Aesthetic*, *Black*.
- `4k phone wallpaper` → Спайдермен, Blood Moon, эмодзи в заголовках.
  Чипы: *Ronaldo*, *Onepiece*, *Solo leveling*, *Max verstappen*, *Ultra hd*.

**Вывод:** слово, выигрывающее в Google, отпугивает нужную аудиторию в Pinterest.
Решение: 4K — факт в метаданных, а не элемент айдентики.

Отдельно: в таксономии Pinterest — «backgrounds», в Google — «wallpaper».

### Русский рынок

`обои на телефон` 67.7 · `улучшить качество фото` 47.5 · `обои 4k` **3.6**.

4K-позиционирование в русском не работает вообще. Зато интент инструмента почти
догоняет интент галереи (в английском соотношение 7:1). Это **другой продукт**,
а не перевод.

### Ограничение метода

Английский корпус смещён в сторону Индии (`krishna` 44, `god` 33, `radha` 21,
`hanuman` 18). **Но** параметр `gl` в endpoint автодополнения игнорируется —
выдача для `us`, `gb`, `in` побайтово идентична. Это глобальный английский,
а не срез по США. Гео-сегментация есть только в Trends.

## 3. Принятые решения

| Тема | Решение |
|---|---|
| Позиционирование | Курируемая галерея; инструмент — монетизация, не SEO-поверхность |
| SEO-канал | Google Images. Страница детали = главная страница |
| Ключевые слова | Только в метаданных. Скрытый текст = клоакинг, не использовать |
| Название | Абстрактное, «artsy-startup», `.com`. Ориентир — **vellum**. Домен НЕ выбран |
| Источник контента | Загрузки пользователей + сид из public domain / open access |
| Правовая модель | DMCA safe harbor: регистрация агента, политика повторных нарушителей, быстрые тейкдауны |
| Аккаунты | Обязательны — иначе некого «терминировать», и safe harbor не работает |
| Дизайн | Направление «реставрация» (см. раздел 5). Одобрено |
| Подписи | Названий нет. Заголовок — размер (`1170 × 2532`), выше инвентарный номер `VL·0001` |
| Строка-слоган | Удалена. Осталась только ссылка-призыв |
| Устройство | Не название модели, а сравнение с экраном посетителя |

**Важная деталь по safe harbor:** он защищает от нарушений **пользователей**,
а не собственных. Всё, что Charlie заливает сам, должно быть public domain,
open access или своим. Друг, заливающий по просьбе Charlie, — это агент,
его действия приписываются Charlie.

## 4. Открытые вопросы

1. **Домен.** Не выбран. Charlie отверг всё, кроме «vellum»: `walls4k`,
   `crispwalls`, `lockscreengallery`, `screenscenery`, `stillscreens`, `wallflower`.
   Нужны абстрактные варианты в регистре «vellum», строго `.com`.
   Проверять **только** через `scripts/research/avail.py`.
2. **Рынок: EN или RU.** Формально не решено, склонялись к EN. Разница не в
   переводе, а в продукте (см. данные по RU выше).
3. **Словарь тегов.** Стал критичным: без названий у страниц почти нет
   индексируемого текста, а размеры повторяются. Теги — единственное описательное
   содержимое и единственная связь с `minimalist wallpaper 4k phone`.
   Решить до того, как накопится 200 неразмеченных изображений.
4. **Соседние работы.** Рекомендация: порядок развески сейчас, теги позже.
   Подобие по эмбеддингам избыточно при трёх изображениях в день.
5. **Монетизация.** Не решена. Воронка «галерея → платный инструмент» слабая:
   интенты разные (потребитель картинки против обработчика своей). В корпусе
   инструментов `free` — 200 вхождений, `online` — 90. Аудитория не хочет платить.
6. **`og:title`** всё ещё содержит «4K phone wallpaper» — это видимая поверхность
   в превью ссылок (Discord, Twitter). Решить, важнее ли там вайб или кликабельность.
7. **Мобильная вёрстка** проверена только принудительным применением медиазапроса.
   Нужен реальный просмотр с телефона.

## 5. Дизайн: направление «реставрация»

Прототип: `prototype-conservation.html` (самодостаточный, без зависимостей).
Запуск: `python3 -m http.server 8777` из корня репозитория, затем
`http://localhost:8777/prototype-conservation.html`.

Подробности и обоснования — в `2026-08-16-conservation-design-prototype.md`.

**Метафора:** не сайт обоев, а лист в паспарту на стене галереи.

| Роль | Цвет |
|---|---|
| Стена | `#232326` |
| Паспарту | `#9A9A94` |
| Срез паспарту | `#86867F` |
| Бумага (текст) | `#EDEAE3` |

Хроматического акцента нет вообще: контент — произвольные изображения,
любой фирменный оттенок будет с ними спорить. Иерархия только по светлоте.

Шрифты: **Newsreader** (размер как заголовок), **Archivo** (интерфейс),
**IBM Plex Mono** (характеристики, инвентарный номер).

**Структура страницы детали:** этикетка сбоку от работы, а не под ней —
так изображение, характеристики и кнопка скачивания помещаются в один экран.
Скачивание ничем не закрыто: гейтинг — признак ad-фермы.

**Ключевой элемент:** «удержать, чтобы сравнить». Изображение возвращается
к исходному разрешению, **и синхронно деградирует типографика** строки
происхождения. Реализовано честно — отрисовка в маленький canvas и обратное
масштабирование с выключенным сглаживанием.

Изображения в прототипе генерируются процедурно. Гряды силуэтов добавлены
намеренно: чистый градиент почти не теряет качества при уменьшении, и без
настоящих краёв сравнение ничего бы не доказывало.

## 6. Инструменты исследования

Скопированы в `scripts/research/` (из временной папки сессии, которая будет удалена):

| Скрипт | Назначение |
|---|---|
| `avail.py` | **Единственный надёжный** способ проверки доменов. IANA RDAP bootstrap → RDAP реестра. `cat domains.txt \| python3 avail.py` |
| `whois.py` | whois по порту 43. Работает для `.com`; для `.co` и Identity Digital — нет |
| `trends.py` | Google Trends. `trends.py <geo> <timeframe> <kw1> [kw2...]` |
| `suggest.py` | Google Autocomplete с развёрткой по алфавиту, корректно кодирует кириллицу |

### Грабли, на которые уже наступили — не повторять

- **`rdap.org` даёт ложные «свободно» для `.co`.** `wallflower.co` был показан
  свободным, хотя занят. Проверяйте `avail.py`, а для `.co` — ещё и DNS
  (`.co` не публикует RDAP, whois-сервер недоступен).
- **В whois сначала проверять `Domain Name:` / `Creation Date:`, потом маркеры
  доступности.** Слово «available» встречается в юридическом футере занятых
  доменов — из-за этого 12 доменов подряд были ошибочно помечены свободными.
- **`whois.nic.gallery` и `whois.nic.studio` отвечают «TLD is not supported»** —
  это Identity Digital, нужен RDAP реестра.
- **Trends нормализует внутри одного сравнения.** Значения из разных запусков
  сравнивать нельзя. `y2k wallpaper` показал 71.0 в своём наборе и 3.4 рядом
  с `4k wallpaper` — это одно и то же число.
- **Не сравнивать огромный общий термин с узкими** — всё остальное схлопывается
  в шум (`zedge` показал 0.4 рядом с `wallpaper`, что неправдоподобно).
- **Google Suggest игнорирует `gl`.** Гео-срез только через Trends.
- **RDAP Verisign блокирует запросы** — для `.com` использовать `whois.py`.
- **Скриншоты Chrome периодически отваливаются по таймауту.** Страница при этом
  жива (проверяется через `javascript_tool`). Просто повторить.
- **Окно Chrome не сжимается уже ~1274px** — мобильную вёрстку проверять
  принудительным применением правил медиазапроса.
