# Удаление карточек моделей из интерфейса

## Цель и решение

Убрать из интерфейса выбора моделей Topaz Image Upscale, Google Upscaler и Nano Banana 2 Lite.

Карточки удалены только из пользовательского интерфейса. В качестве модели по умолчанию выбран Real-ESRGAN — первая доступная карточка.

## Изменения

- `public/index.html`: удалены три карточки моделей; `real_esrgan` сделан выбранным по умолчанию.

## Проверки и ограничения

- Конфигурации удалённых карточек остаются на сервере, поэтому прямой API-запрос с соответствующим идентификатором по-прежнему обрабатывается согласно серверным правилам.
- Синтаксическая проверка сервера не требуется: изменён только HTML.
