# Проверка 2K и 4K для обычных изображений

## Цель и решение

Проверить возможность добавить кнопки 2K и 4K для моделей вкладки «Обычные изображения».

Проверены актуальные схемы моделей в Replicate. Real-ESRGAN, GFPGAN и CodeFormer не принимают целевое разрешение в пикселях: у них есть только масштаб относительно исходного изображения (`scale` или `upscale`). Поэтому кнопки с подписями «2K» и «4K» не смогут гарантировать результат 2048 или 4096 пикселей по длинной стороне.

## Результаты

- `nightmareai/real-esrgan`: `scale` — число от 0 до 10, по умолчанию 4.
- `tencentarc/gfpgan`: `scale` — коэффициент масштабирования, по умолчанию 2.
- `sczhou/codeformer`: `upscale` — целочисленный коэффициент, по умолчанию 2.

## Рекомендуемые варианты

1. Добавить кнопки «×2» и «×4» — корректно отражают возможности всех трёх моделей.
2. Добавить «2K» и «4K» с постобработкой на сервере: после апскейла приводить длинную сторону к 2048 или 4096 пикселям. Для этого нужна дополнительная библиотека обработки изображений и нужно решить, допускается ли уменьшение уже готового результата.

## Ограничения

- При фиксированном 2K/4K итоговая короткая сторона зависит от соотношения сторон исходного изображения.
- Платные задачи не запускались; схемы параметров прочитаны через API Replicate без создания задач.
