# Машина

Выкладка — `./scripts/deploy.sh`; что он делает, видно в нём самом. Здесь
описано то, чего в репозитории нет и по коду не восстанавливается: устройство
боевой машины.

`ssh root@145.223.96.83` (Ubuntu, `srv668198`).

| | |
|---|---|
| Адрес | https://tessarum.com/ (`www` уходит редиректом на голый домен) |
| Каталог | `/opt/apps/upscaler` — не рабочая копия git, туда кладёт rsync |
| Секреты | `/opt/apps/upscaler/.env` |
| Коллекция | `/opt/apps/upscaler/images`, том в контейнер |
| Журнал | `/opt/apps/upscaler/log`, том в контейнер |
| Рассылка | `/opt/apps/upscaler/mail`, том в контейнер |
| Контейнер | `upscaler`, сеть `n8n_default`, внутренний порт 3000 |
| Маршрут | `/opt/traefik-dynamic/upscaler.yml` |

## Traefik чужой

TLS и маршрутизацию держит контейнер `n8n-traefik-1` — он из другого проекта
на этой же машине, и в `docker-compose.yml` сеть `n8n_default` объявлена
`external` именно поэтому. Отсюда два следствия.

Первое: порт 3000 наружу не публикуется, снаружи в контейнер ходит только
Traefik, по имени `upscaler`. Второе важнее: **файл маршрута лежит вне
репозитория**, и ничто здесь на него не ссылается. Пропадёт
`/opt/traefik-dynamic/upscaler.yml` — домен перестанет вести куда бы то ни было,
а по этому репозиторию догадаться, где искать, будет не по чему. В нём же
живёт редирект с `www` и `certResolver: mytlschallenge`, которым берётся
сертификат.

## Что должно быть в `.env` на машине

Имена, не значения. Значения не переносите в документы, логи, коммиты и чат.

- `REPLICATE_API_TOKEN` — без него `/api/upscale` отвечает 503, а витрина
  работает целиком.
- `KIE_API_KEY` — от прежнего изготовителя картинок.

Остальное задано в `docker-compose.yml` и потому видно в git.

## Чего на машине нет

**Резервного копирования.** `images/` на сервере — одна из двух копий того,
что не лежит в git; вторая на машине разработчика.

**Памяти о счётчиках.** `limits.js` считает вызовы в памяти процесса, и после
каждой выкладки суточный потолок начинает полсотни заново.

## Журнал запросов

Единственная память сайта о том, кто приходил. Маяк Cloudflare режется
блокировщиком и считает только загруженные страницы, поэтому считает и сервер
— правила записи и довод о том, почему баннер согласия от этого не появляется,
в `journal.js`.

Лежит в `/opt/apps/upscaler/log`, файл на сутки, полгода в сумме; старое
сервер подметает сам. Том, а не каталог образа: пересборка не должна стирать
статистику. `rsync --delete` из `deploy.sh` до него не достаёт — он синхронизирует
перечисленные каталоги, а не весь `$DIR`, — но том в `docker-compose.yml`
всё равно обязателен: без него журнал пишется внутрь контейнера и умирает
с ним.

Каталог принадлежит `1001:1001` — тому же, от кого работает процесс в образе.
Заводит его `deploy.sh` перед пересборкой; если каталог создать руками от root,
запись отвалится по правам, но сайт останется жив, а журнал — пустым.

Читать — сводкой, а не глазами:

```bash
ssh root@145.223.96.83
docker exec upscaler node scripts/journal-rollup.mjs --days 7
docker exec upscaler node scripts/journal-rollup.mjs --days 7 --sample 10
```

`--sample` печатает случайные заходы целиком, чтобы разметить их рукой:
«бот или человек» — правило «да/нет», и без ручных ярлыков его точность
и полнота неизвестны, а от него зависит каждое число в сводке.

Адреса посетителей в файлах нет. Заход склеивается по восьми знакам хэша,
в который идёт соль, рождающаяся в памяти при старте и никуда не
сохраняемая: перезапуск делает прежние заходы неразличимыми навсегда.
Отсюда же известная цена — **выкладка посреди дня разрезает одного
посетителя на двух**, и в сводке за этот день заходов будет больше,
чем людей.

## Список рассылки

Единственные персональные данные, которые сайт хранит. Лежат в
`/opt/apps/upscaler/mail/subscribers.tsv`, три столбца: время, адрес и та из
двух форм, что сработала (строка под сеткой или страница `/mailing-list`).
Правила записи — в `mailing.js`.

Каталог свой, отдельный от `log/`, и это не аккуратность: журнал обещает, что
личного в нём нет вовсе, и почтовый адрес в нём отменил бы это обещание задним
числом — для всего, что уже записано. Том обязателен по той же причине, что
и у журнала: без него файл живёт внутри контейнера и умирает с пересборкой.
Права те же, `1001:1001`, и заводит каталог `deploy.sh`.

Рассылки при этом пока нет: писем никто не шлёт, подтверждения адреса
(double opt-in) нет, отписки нет. То есть список сейчас — просто список тех,
кто оставил адрес, и первое же письмо по нему будет письмом людям, которые
подписались, но своего адреса нам не подтверждали (TODO.md).

Смотреть — по ssh, а не маршрутом: маршрута, отдающего этот файл, нет
и заводить его незачем.

```bash
ssh root@145.223.96.83
docker exec upscaler sh -c 'wc -l < /app/mail/subscribers.tsv'
```

## Проверка

`deploy.sh` в конце сам показывает статус контейнера и три кода ответа.
Глубже — сравнить витрину с каталогом: адресов в карте сайта должно быть
на три больше, чем работ без `hidden`, — витрина, условия и приёмка тоже
адреса.

`/api/upscale` для проверки не зовите: это настоящий платный запрос
в Replicate.
