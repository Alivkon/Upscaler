Вся сборка и запуск пакетов делаются через `yarn`:

```bash
yarn install
yarn build 
yarn start

```

## Журнал работы

После каждого существенного шага создавай новый документ в папке `research` с названием в формате `YYYY-MM-DD-<тема>.md ` и`YYYY-MM-DD-<тема>.html` (для HTML-страниц). Файл должен содержать:
- цель и принятые решения;
- выполненные изменения с указанием файлов;
- результаты проверок и известные ограничения;
- ссылки на использованные источники, если проводилось исследование.

Не записывай скрытые внутренние рассуждения; фиксируй только краткие, проверяемые обоснования решений и результаты работы.
