Вся сборка и запуск пакетов делаются через `yarn`:

```bash
yarn install
yarn build 
yarn start

```
В начале каждой сессии раздумий над задачёй и при работе в __Act mode__ создавай новый документ в папке `research` с названием в формате `YYYY-MM-DD-<тема>.md`. В нём фиксируй все свои мысли, идеи, гипотезы и результаты экспериментов. Это поможет отслеживать прогресс и возвращаться к предыдущим идеям при необходимости.
